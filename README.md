# Fuel Prep

## Client

**James Halvorson** is a fitness enthusiast interested in helping people simplify healthy eating and meal preparation while staying within a budget.

---

## Project Description

Fuel Prep is a responsive landing page for a meal-planning platform designed to help students, busy professionals, and fitness enthusiasts achieve their nutrition goals. The website introduces the Fuel Prep concept, explains how the platform works, and allows users to submit information through a lead-generation form.

Users can enter details such as their fitness goals, calorie targets, dietary restrictions, and grocery budgets. The website demonstrates how Fuel Prep will eventually generate personalized meal recommendations and budget-friendly grocery shopping lists using AI-powered meal planning.

The website includes:

* Home page
* How It Works page
* About page
* Responsive navigation
* Lead capture forms
* Dashboard mockup
* Local Storage functionality to save user inputs
* Mobile-friendly design using CSS Grid and Flexbox

## What I Learned

Through this project, I learned how to design and build a multi-page responsive website using HTML and CSS. I gained experience creating consistent navigation across multiple pages, implementing semantic HTML elements, and designing layouts with CSS Grid and Flexbox.

I also learned how to:

* Use external CSS stylesheets to organize code
* Create responsive layouts that work on different screen sizes
* Implement forms with HTML validation
* Store user-submitted data using JavaScript Local Storage
* Deploy a website using GitHub Pages
* Use Google Fonts and modern UI design principles
* Build a landing page based on a Product Requirements Document (PRD)

One of the most valuable lessons from this project was understanding how to translate a client's requirements and business goals into a functional website design. I also learned how front-end websites can collect and temporarily store user data without requiring a backend database.
